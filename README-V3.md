# برنامج خدمات قرية الحرية — V3

هذه النسخة تعالج خطأ `login_by_code` بطريقة مختلفة: نظام الدخول نفسه موجود بالكامل داخل `schema.sql` ويستخدم جلسة خاصة بالتطبيق، وليس Supabase Auth للمستخدمين النهائيين.

## الرموز
- المشرف 1: `FREEDOM-ADM-01`
- المشرف 2: `FREEDOM-ADM-02`
- المشرف 3: `FREEDOM-ADM-03`
- المستخدم: `FREEDOM-USER`

## التشغيل الصحيح
1. افتح مشروع Supabase المرتبط بالتطبيق.
2. افتح SQL Editor.
3. انسخ/نفّذ **الملف الوحيد `supabase/INSTALL-V3.sql` كاملاً مرة واحدة**.
4. انشر محتويات هذا المجلد إلى GitHub Pages.
6. افتح الموقع في نافذة خاصة/بعد تحديث قوي.

لا تضع Service Role Key داخل ملفات الموقع. النسخة تستخدم Publishable/Anon key فقط.

## ملاحظة مهمة
هذا ZIP يحتوي على إعداد قاعدة البيانات، لكنه لا يستطيع تنفيذ SQL داخل حساب Supabase من تلقاء نفسه لأن ذلك يتطلب صلاحية إدارة قاعدة البيانات. لذلك تنفيذ ملفي SQL هو خطوة الإعداد الوحيدة خارج ملفات الموقع.

## وظائف V3
- دخول بالرمز.
- 3 حسابات مشرف منفصلة.
- حساب مستخدم منفصل.
- جلسة دخول لمدة 30 يوماً مع رمز عشوائي لا يُخزن نصه في قاعدة البيانات.
